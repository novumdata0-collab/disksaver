# DiskSaver — план приложения

## 1. Суть

1. Подключаете диск (HDD/SSD, SATA, USB-бокс, док-станция).
2. Приложение замечает новый том и предлагает просканировать его.
3. Быстро находит нужные файлы: документы, таблицы, фото и т.д.
4. Показывает их по категориям, пользователь отмечает галочками, что сохранить.
5. Копирует отмеченное на диск-архив и проверяет каждую копию.
6. Только после успешной проверки предлагает отформатировать старый диск.

## 2. Технологии

| Что | Выбор | Почему |
|---|---|---|
| Язык/платформа | C# / .NET 8 | Нативно для Windows, быстрый I/O, один exe |
| UI | WPF | Списки с галочками, таблицы, трей |
| Хранение путей | SQLite (`Microsoft.Data.Sqlite`) | Пути сохраняются между запусками |
| Детект диска | `WM_DEVICECHANGE` / WMI `Win32_VolumeChangeEvent` | Событие приходит сразу при подключении |
| Проверка копий | xxHash (`System.IO.Hashing`) | Очень быстрая проверка |

## 3. Модули

```
DiskSaver/
├── DriveWatcher      — следит за подключением дисков
├── Scanner           — обходит диск, раскладывает файлы по категориям
├── Catalog (SQLite)  — хранит найденные пути
├── CopyEngine        — копирует и проверяет копии
├── FormatHelper      — безопасное форматирование
├── Settings          — категории, расширения, исключения
└── UI                — трей, главное окно, мастер копирования
```

### 3.1 DriveWatcher
- Ловит появление тома, показывает уведомление «Обнаружен диск E: — сканировать?».
- USB-HDD часто определяется как `Fixed`, поэтому новый диск ищем по разнице в списке дисков «до/после».
- Системный диск и диск-архив никогда не трогаем.
- Диск опознаём по серийному номеру тома, а не по букве.

### 3.2 Scanner
- **v1:** `FileSystemEnumerable` с `IgnoreInaccessible`, без reparse points.
- **v2:** чтение MFT через `FSCTL_ENUM_USN_DATA` (как Everything), нужны права администратора. Если прав нет или диск не NTFS, используется v1.
- Исключения: `Windows`, `Program Files*`, `ProgramData`, `$Recycle.Bin`, `System Volume Information`, `AppData\Local\Temp`, кэши, `node_modules`.
- Фильтр мелких картинок (< 30 КБ).
- Результаты появляются по ходу сканирования, сканирование можно отменить.

| Категория | Расширения |
|---|---|
| Документы | doc, docx, odt, rtf, pdf, txt |
| Таблицы | xls, xlsx, xlsm, csv, ods |
| Презентации | ppt, pptx, odp |
| Фото | jpg, jpeg, png, heic, bmp, tiff, webp, cr2, cr3, nef, arw, dng, orf |
| Видео | mp4, mov, avi, mkv |
| Архивы | zip, rar, 7z |
| Прочее | задаёт пользователь |

### 3.3 Catalog (SQLite)
```sql
drives(id, serial, label, size, fs, first_seen, last_scan)
files(id, drive_id, rel_path, name, ext, category, size, mtime,
      selected, copy_status, hash)
```

### 3.4 Главное окно
- Слева категории с количеством и объёмом, справа таблица файлов с галочками.
- Поиск, фильтр, открыть папку, экспорт списка в CSV.
- Кнопка «Копировать выбранное».

### 3.5 CopyEngine
1. Выбор диска-архива, проверка свободного места.
2. Режимы: сохранить структуру папок `Archive\<метка>_<дата>\...` или разложить по категориям.
3. Порядок: сначала мелкие ценные файлы (документы/таблицы), потом крупные.
4. Проверка каждой копии: размер + хеш.
5. При совпадении имён: `файл (2).docx`, без перезаписи.
6. Ошибки записываются в лог, копирование продолжается, в конце отчёт.
7. В архив кладётся `manifest.csv`.

### 3.6 FormatHelper
- Доступен только после копирования без ошибок.
- Запрещено форматировать системный диск, диск-архив и диск, с которого запущено приложение.
- Подтверждение: ввести букву диска вручную.
- Форматирование через стандартное окно Windows `SHFormatDrive`.

## 4. Этапы

| Этап | Что входит |
|---|---|
| 1. MVP | Выбор диска, сканирование, категории, список с галочками, копирование с проверкой, лог, manifest |
| 2. Автоматика | Трей, автоопределение диска, SQLite |
| 3. Надёжность | Пауза и продолжение копирования, хеш-проверка, приоритеты |
| 4. Скорость | Чтение MFT, дубликаты, предпросмотр |
| 5. Финал | Форматирование, настройки, публикация single-file exe |

## 5. Риски
- BitLocker: показать сообщение «разблокируйте диск».
- Умирающий HDD: не сканировать повторно, в тяжёлых случаях лучше снять образ диска.
- Пути длиннее 260 символов: .NET 8 их поддерживает.
- Нет доступа к чужим папкам пользователей: запуск от администратора по желанию.
- exFAT/FAT32: только обычное сканирование.

## Структура и запуск
```
src/DiskSaver.Core   — логика (категории, DiskScanner, CopyEngine, DriveService)
src/DiskSaver        — WPF-интерфейс (MVVM)
```
**Запуск: двойной клик по `DiskSaver.exe` в корне проекта** (один файл, .NET не нужен).

Пересборка exe:
```
dotnet publish src/DiskSaver -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

SDK установлен локально: `%USERPROFILE%\.dotnet\dotnet.exe`.
```
dotnet run --project src/DiskSaver # запуск
```
